# Тестовое задание

Приложение получает сделки через workflow n8n и отображает их в динамической HTML-таблице.

## Структура проекта

```text
├── php/
│   └── index.php
├── n8n/
│   └── workflow.json
└── README.md
```

PHP выполняет один GET-запрос к n8n. Workflow получает список ID сделок, запрашивает данные каждой сделки и возвращает готовый список для таблицы.

Адреса внешнего API вынесены в отдельный узел `Конфигурация апи`. Входной запрос, структура ответа и поведение при частичной ошибке описаны в Sticky Note внутри workflow.

## Формат ответа n8n

```json
{
  "success": true,
  "total": 10,
  "data": [
    {
      "id": 1001,
      "title": "Сделка с ООО Ромашка",
      "amount": 1250000,
      "responsible": {
        "id": 12,
        "name": "Иван Петров"
      },
      "company": {
        "id": 78,
        "name": "ООО Ромашка"
      }
    }
  ],
  "errors": []
}
```

Если одна из сделок не загрузилась, остальные данные все равно возвращаются:

```json
{
  "success": false,
  "total": 1,
  "data": [
    {
      "id": 1001,
      "title": "Сделка с ООО Ромашка",
      "amount": 1250000,
      "responsible": {
        "id": 12,
        "name": "Иван Петров"
      },
      "company": {
        "id": 78,
        "name": "ООО Ромашка"
      }
    }
  ],
  "errors": [
    {
      "id": 999999,
      "message": "Сделка с ID 999999 не найдена"
    }
  ]
}
```

## Обработка ошибок

В запросе отдельной сделки включена настройка `Never Error`, из-за чего ошибка одного ID не останавливает весь workflow.

Успешные сделки помещаются в `data`, а ошибки отдельных запросов — в `errors`. Поле `total` содержит количество успешно загруженных сделок.

## Запуск workflow

1. Открыть n8n Cloud или локальную установку n8n.
2. Выбрать **Import from File** и загрузить `n8n/workflow.json`.
3. Открыть импортированный workflow.
4. Опубликовать или активировать workflow.
5. Открыть узел Webhook и скопировать его **Production URL**.
6. Указать скопированный адрес в переменной `$n8nUrl` файла `php/index.php`.

Webhook использует путь:

```text
/webhook/api/test.task/get.deals
```

## Запуск PHP на компьютере

Требования:

- PHP 8.0 или новее;
- расширение cURL.

Открыть терминал в корневой папке репозитория — там, где находятся папки `php` и `n8n`.

Выполнить:

```bash
php -S localhost:8000 -t php
```

Не закрывая терминал, открыть в браузере:

```text
http://localhost:8000
```

Для остановки сервера нажать `Ctrl+C`.

## Запуск в GitHub Codespaces

1. На странице репозитория нажать **Code → Codespaces**.
2. Создать или открыть Codespace.
3. В верхнем меню выбрать **Terminal → New Terminal**.
4. Из корня репозитория выполнить:

```bash
php -S 0.0.0.0:8000 -t php
```

5. Открыть вкладку **Ports**.
6. Найти порт `8000` и нажать **Open in Browser**.
